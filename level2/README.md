# 🎙️ Level 2 — المدير الشخصي التنفيذي (حوار حي + استشارة)

> **ما هذا؟** مديرك الشخصي الذي **تتكلم معه صوتًا** ويستشيرك للتحسين — مبنيًا على
> بروتوكولاتك الموثقة في الشيت المرجعي (مصفوفة الإرشادات + سرعة القرار + نقاط الضعف
> + العبارات التوجيهية + بروتوكول الطاقة).

> **فلسفة Level 2:** تنفيذ داخلي قابل للعكس + تقرير (L2). المدير ينشئ المهام ويسجل
> القرارات ويحدث سجلاتك فورًا ويخبرك — وكل ما يمس الخارج (رسائل/مدفوعات/نشر) يبقى
> **اقتراحًا** لا ينفذ أبدًا من تلقاء نفسه.

## ⚡ التشغيل (VS Code — دقيقتان)

```bash
# 1) افتح Terminal في VS Code (Ctrl+`) من مجلد المستودع
python3 -m level2.server

# 2) افتح المتصفح:  http://localhost:8765
#    اضغط زر 🎙️ وتحدث — سيرد عليك صوتًا.
```

**لا يحتاج أي شيء غير Python المثبت لديك.** لا مفاتيح، لا إنترنت، لا قاعدة بيانات،
لا Git. الصوت (استماع + نطق) عبر Web Speech API في المتصفح (Chrome/Edge).

### جسر تيليجرام (اختياري — خارج البيت)

```bash
TELEGRAM_BOT_TOKEN=ضع_توكن_بوتك python3 -m level2.telegram_bridge
```

نفس العقل، نفس الحالة المحلية، نفس البروتوكولات — يرد على من يكتب البوت فقط.

### استيراد بياناتك (مرة واحدة)

```bash
python3 -m level2.migrate                 # تلقائي: من الشيت المُصدَّر ومن النظام القديم
python3 -m level2.migrate --sheet ملف.xlsx  # أو حدد الملف يدويًا
```

استورد فعليًا عند البناء: **25 مهمة مفتوحة · 1 قرار معلق · 2 عنصر انتظار** من نسخة
الشيت الاحتياطية — بلا أرقام مالية (احترامًا لقرارك بإزالتها).

## 🧠 الوضعان

| الوضع | متى | كيف |
|---|---|---|
| **حتمي محلي** (افتراضي) | دائمًا يعمل | البروتوكولات المستخرجة من الشيت ترد مباشرة — صفر API |
| **نموذج لغوي** (اختياري) | إن أردت حوارًا أغنى | `LLM_BASE_URL` + `LLM_MODEL` — أي نقطة متوافقة مع OpenAI |

```bash
# مثال: نموذج محلي مجاني عبر Ollama (لا إنترنت أصلًا)
LLM_BASE_URL=http://localhost:11434/v1 LLM_MODEL=qwen3:8b python3 -m level2.server

# أو مزودك الخاص (OmniRoute أو غيره) — سرّك يبقى في جهازك في ملف .env
LLM_BASE_URL=https://مزودك/v1 LLM_API_KEY=... LLM_MODEL=... python3 -m level2.server
```

في كل الأحوال: **الأثر الداخلي (مهام/قرارات) يُنفذ حتميًا بالكود**، والنموذج يصوغ
الكلام فقط — فشل النموذج أو الشبكة لا يعطل المدير أبدًا (رجوع تلقائي للوضع الحتمي).

## 🗂️ البنية (6 ملفات منطق فقط)

```
level2/
├── server.py           خادم محلي (Python قياسي) — واجهة الصوت + API
├── agent.py            عقل المدير: تصنيف النية + ردود البروتوكولات
├── protocols.py        ← بروتوكولاتك من الشيت (عدّل النصوص هنا لضبط شخصيته)
├── identity.py         هويتك SC/5w6 + قواعد أسلوب الحوار
├── state.py            الحالة المحلية (JSON ذرّي + 7 نسخ دوّرة) — بديل Sheets/Supabase
├── llm.py              جسر النموذج الاختياري (OpenAI-compatible)
├── telegram_bridge.py  قناة تيليجرام الاختيارية
├── migrate.py          استيراد بياناتك القديمة
├── static/index.html   واجهة الحوار الصوتي (RTL)
└── data/level2_state.json   ← بياناتك (مستثناة من Git تلقائيًا)
```

## 💬 الأوامر الصوتية (جرّبها)

| قل | يحدث |
|---|---|
| «بريف» | أولويتان + قرار واحد معلق + تحذيرات (قاعدة M3) |
| «مهمة: العنوان قبل 2026-10-12» | تسجيل مهمة + مطالبة بإجراء 48 ساعة |
| «أنجزت + رقم/عنوان المهمة» | إغلاق + طلب دليل الإنجاز |
| «قرار: ...» | استشارة خيارين (أ/ب) + 70% يقين + مهلة 24 ساعة |
| «أعاني من الكمالية/التسويف/...» | بروتوكول نقطة الضعف (29 نقطة) |
| «طاقتي 4» | تسجيل الطاقة — عند الانخفاض يفعّل بروتوكول الإرهاق |
| «تأمل» | تقنية هدوء فورية (15 تقنية) |
| «عبارة لطلب مساعدة مفاجئ» | الرد الجاهز من مكتبة العبارات (28 موقفًا) |
| «فكرة: ...» | حفظ في صندوق الاحتمالات (لا تشتت — قاعدة M6) |
| «مراجعة أسبوعية» | قياس: مهام منجزة، قرارات محسومة، طاقة، حكم |
| «الانتظار» | الحلقات المفتوحة + تصعيد ما تجاوز 14 يومًا |
| «حالة النظام» | تشخيص ذاتي |

## 🔧 التطوير من VS Code — أين تعدل ماذا

- **شخصية المدير / نصوص الردود** → `protocols.py` (كل شيء نص واضح مع تعليقات)
- **نية جديدة** → أضف سطرًا في `INTENTS` داخل `agent.py` + دالة رد
- **حقل جديد في الحالة** → `state.py` (المهام/القرارات/الانتظار/الطاقة)
- **الواجهة** → `static/index.html` (ملف واحد: HTML+CSS+JS بلا أطر)
- **اختبار سريع بلا متصفح**:
  ```bash
  python3 -c "from level2.agent import handle; print(handle('بريف')['reply'])"
  ```

## 🛡️ خصوصية وحوكمة

- بياناتك في ملف JSON واحد على قرصك + 7 نسخ دوّرة بجواره — **لا سحابة، لا مفاتيح، لا رفع تلقائي**
- `level2/data/` مستثنى من Git في `.gitignore` — لا تصل حالتك لأي مستودع
- لا يُرسل شيء لأي طرف إلا: ردك على رسالة تيليجرام تكتبها أنت (وفي جسر تيليجرام فقط)
- مستوى الاستقلالية L2: الخارج اقتراح دائمًا
