# 📱 ربط تيليجرام — دقيقتان قبل النوم

## الخطوات
1. افتح تيليجرام ← ابحث عن **@BotFather** ← أرسل `/newbot`
2. اسم البوت: `Abdulrahman AI OS` (مثال) ← ثم معرف مثل `abdulrahman_aios_bot`
3. انسخ التوكن (`123456:ABC-...`)
4. شغّل البوت:
```bash
TELEGRAM_BOT_TOKEN="التوكن-هنا" python3 engine/telegram_bot.py
```
5. من جوالك (نفس حسابك) افتح البوت وأرسل `/start` — **أول محادثة تملك القناة تلقائيًا**، وأي معرف آخر يُرفض ويُسجل أمنيًا في التدقيق
6. جرّب: `/brief` ثم `/approve`

## أوامرك (من جوالك)
| الأمر | الوظيفة |
|---|---|
| `/brief` | أحدث بريف صباحي كامل |
| `/approve` | مسودات الاعتماد **بأزرار ✅/❌** (مربوطة ببصمة المحتوى — قاعدة C2) |
| `/decisions` | طلبات القرار المفتوحة بأزرار خيارات (حسم فوري يُسجل بالسجل) |
| `/tasks` `/reviews` `/door` `/mastery` | مهامك · مراجعات اليوم · باب اليوم · خريطة الإتقان |
| `/answer LR-001 85` | تسجيل درجة مراجعة |
| **أي نص** | يُلتقط فورًا إلى صندوق يومك 📥 |

## الإشعارات التلقائية
- إجراء جديد يدخل الطابور → يصلك بأزرار الاعتماد فورًا
- البريف الصباحي يوصلك 6–9 صباحًا تلقائيًا (مرة يوميًا)

## تشغيل دائم (اختياري — بعد التأكد من عمله)
- ويندوز: أنشئ اختصارًا في مجلد بدء التشغيل يشغّل:
  `cmd /c set TELEGRAM_BOT_TOKEN=xxx && python -u engine\telegram_bot.py >> logs\telegram.log 2>&1`
- ماك/لينكس: LaunchAgent/service ثانية مثل `autostart/` الحالية

## أمان
- التوكن متغير بيئة فقط — لا يُخزن في أي ملف ولا يُرفع للمستودع
- قناة أحادية المالك + توثيق أي محاولة دخول غريب في `data/audit.jsonl`
- البوت لا يرسل أي شيء خارجيًا بنفسه: يعرض، وأنت تعتمد بزر — ثم التنفيذ اليدوي/اللاحق
