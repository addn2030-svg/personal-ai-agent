# clinical-note-drafting

## Purpose
صياغة مسودات التوثيق السريري (SOAP) داخل حدود المصنف السريري المحمي فقط.

## Procedure
قواعد صارمة:
1. التوثيق السريري لا يمر إلا عبر مسار CLINICAL_PRIVATE (clinical_sheet) — ممنوع
   أي معرف مريض أو تفصيل سريري في السجلات العامة أو Supabase العامة أو المحادثات.
2. البنية: Subjective (شكوى المريض بكلماته + التغير منذ الجلسة السابقة) —
   Objective (القياسات المرقمة فقط: ROM بالدرجات، قوة MMT 0-5، ألم NRS) —
   Assessment (تفسير قصير: ما الذي تحسن/تدهور ولماذا فرضيًا) —
   Plan (الجرعة القادمة مع تعديل واحد وسببه).
3. اللغة: بلا تشخيص جديد لم يقرره المالك، بلا «تحسن ممتاز!» — أرقام ومعطيات.
4. في نهاية كل مسودة: سطر «مسودة للمراجعة — الاعتماد النهائي للمالك».
5. عند الطلب، تُصدَّر المسودة إلى المصنف السريري المحمي وحده بعد اعتماد صريح.

## Safety
Risk tier: locked. External effects remain approval-gated.
