# outcome-measures-rehab

## Purpose
اختيار وتفسير مقاييس النتائج الموثقة علميًا حسب المنطقة + أصغر فرق مهم سريريًا (MCID).

## Procedure
المكتبة المرجعية (كل مقياس: ماذا يقيس، نطاق الدرجات، MCID التقريبي):
- قطني: Oswestry Disability Index (0-100، MCID ≈ 10 نقاط).
- عنقي: NDI (0-50، MCID ≈ 5)، وBPPV: DHI.
- كتف: DASH (0-100، MCID ≈ 10-15) / QuickDASH (11 بندًا).
- طرف سفلي: LEFS (0-80، MCID ≈ 9)، الورك: HOS.
- توازن/سقوط (مسنّون): Berg Balance Scale (0-56؛ <45 = خطر سقوط)، TUG (>12 ث = خطر)،
  6MWT (MCID ≈ 25-35 م) — استخدم اثنين فقط لكل مريض: واحد وظيفي + واحد نوعي حياة (EQ-5D).
- ألم: VAS/NRS 0-10 (MCID ≈ 2 نقطة أو 30%).
قواعد:
1. مقياس واحد أساسي ثابت طول البرنامج (تغييره يفسد المقارنة) + واحد تكميلي اختياري.
2. قِس في: التقييم الأول، منتصف البرنامج، النهاية — لا كل جلسة.
3. أبلغ النتيجة كفرق عن الأساس مقابل MCID («تحسن 14 نقطة ODI = تجاوز عتبة التحسن المهم») —
   لا كنسبة مئوية خام مضللة.
4. إن لم يوجد مقياس موثق للحالة: قل ذلك صريحًا ولا تخترع مقياسًا.
