# 🔌 بدء التشغيل التلقائي — اجعل النظام حيًا 24/7

> بعد هذه الخطوة: **بريف الساعة 6:00 صباحًا بتوقيت الرياض يتولد وحده**، والمسح السريع كل 15 دقيقة يشتغل وحده، ولو كان الجهاز نائمًا وقت البريف **يُعوّض فور استيقاظه** (catch-up). لا تحتاج فتح أي شيء.

> ⚠️ متطلب واحد: تثبيت **Python 3** على جهازك مع `pip install openpyxl`، واستنساخ المستودع أولًا.

---

## 🪟 ويندوز (الأكثر احتمالًا عندك) — دقيقتان

1. انقر يمينًا على `autostart\windows\install-autostart.bat` ← **Run as administrator** (أو دبل كليك عادي إن لم يُطلب).
2. انتهى ✅ — المهمة «Abdulrahman AI OS - Manager Loop» تعمل الآن **وعند كل تسجيل دخول**، مخفية تمامًا (لا نافذة).

**التأكد أنه حي:**
```bat
type logs\manager-loop.log          :: ترى سطر التشغيل والدورات
findstr manager_loop_alive data\audit.jsonl   :: نبض اليوم موجود؟
```
**اللوحة تتحدث تلقائيًا** كل صباح: افتح `reports\dashboard-latest.html` (ثبّتها في المتصفح كتطبيق أو اجعلها صفحتك الرئيسية).

**الإيقاف/الإزالة:** `autostart\windows\stop-and-remove.bat`

## 🍎 ماك — دقيقة واحدة
```bash
bash autostart/macos/install.sh
tail -f ~/Library/Logs/aios-manager.log    # التأكد أنه حي
```
LaunchAgent مع **KeepAlive**: لو سقطت الحلقة لأي سبب تُعاد تلقائيًا.
**الإيقاف:** `launchctl unload ~/Library/LaunchAgents/com.abdulrahman.aios.plist`

---

## 🐧 لينكس — دقيقة واحدة
```bash
bash autostart/linux/install.sh
systemctl --user status aios-manager
journalctl --user -u aios-manager -f
```
مع `enable-linger` تعمل الخدمة حتى دون جلسة مفتوحة.

## 📖 كيف تتأكد يوميًا أنه حي؟ (3 نظرات)

## 🔧 ملاحظات خبير
- **استهلاك الموارد شبه معدوم:** حلقة Python خفيفة تنام 30 ثانية بين الفحوص، وتكتب في الحالة **فقط عند التغيير** (write-on-change).
- **اللابتوب يغلق الليل؟** لا مشكلة — عند أول إقلاع بعد السادسة يكتشف أن بريف اليوم لم يُولّد فيولّده فورًا (علامة `last_full`).
- **الفترة المثالية للجهاز:** يكفي أن يعمل من 6:30 إلى 7:00 صباحًا — الوقت الذي تشرب فيه قهوتك وتقرأ البريف.
- **بديل أخف** (لو لا تريد خدمة دائمة): مهمة مجدولة في Task Scheduler تشغّل `update.bat` يوميًا الساعة 6:30 — تحصل على البريف دون حلقة مستمرة.

> تذكير بالحوكمة: الحلقة **لا ترسل شيئًا ولا تنفذ شيئًا خارجيًا** — كل ما تنتجه مسودات في طابور اعتمادك (قاعدة C2). حتى لو فشلت، لا خطر خارجيًا.
