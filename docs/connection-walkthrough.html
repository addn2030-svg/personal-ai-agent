Phase A · once only · ~10 min

🅰 Google Cloud: project + service account + key

This is the single identity your agent uses for Sheets, Drive, Docs and Calendar.

  1. Where Open console.cloud.google.com and sign in with your Google account.
    How Top-left bar → click the project dropdown (next to the Google Cloud logo) → New Project.
  2. What Project name: Abdulrahman AI OS → Create. Wait ~30 seconds, then make sure the project is selected in the top-left dropdown.
  3. Where ☰ menu → APIs & Services → Library.
    What Search each name below → open it → press Enable, one by one:
    Google Sheets APIGoogle Drive APIGoogle Docs APIGoogle Calendar API
  4. Where ☰ → APIs & Services → Credentials → + Create Credentials → Service Account.
    What Name: abdulrahman-agent → Create and Continue → on the "role" step just press Continue (no role needed) → Done.
  5. Where Still on Credentials: under Service Accounts click the new email → tab Keys → Add Key → Create new key → JSON → Create.
    What A .json file downloads to your computer. Keep it private — it is the password.
  6. What Open the downloaded JSON and copy two things:
    • client_email — looks like abdulrahman-agent@abdulrahman-ai-os.iam.gserviceaccount.com (you'll share Google assets with this email)
    • the whole file content — you'll paste it into Railway in Phase F.
Priority 1 · Calendar · meeting Sept 14

📅 Google Calendar

Lets the agent read your schedule and create confirmed events with Telegram reminders.

  1. Where calendar.google.com → left side My calendars → hover your calendar → ⋮ → Settings and sharing.
  2. Where Section "Share with specific people" → Add people.
    How Paste the client_email from Phase A → set permission "Make changes to events" → Send.
  3. Where Same settings page → scroll to "Integrate calendar".
    What Copy the Calendar ID (often your email, or …@group.calendar.google.com).
    Do not use the word primary — it does not work with service accounts.
  4. Where Railway → your service → Variables:
    GOOGLE_CALENDAR_ID = the calendar ID you copied MANAGER_TIMEZONE = Asia/Riyadh
Priority 2 · Docs · formal letters

📝 Google Docs

The new connector drafts letters/reports for you. Documents stay drafts — sending stays behind your approval.

  1. Where docs.google.com → create a blank document, name it e.g. AI OS — Letters (or open an existing one).
  2. How Click Share (top right) → paste the client_email → Editor → Done.
  3. What Copy the document ID from the URL — the long code between /d/ and /edit:
    https://docs.google.com/document/d/←THIS-PART→/edit
  4. Where Railway → Variables:
    GOOGLE_DOCS_DOCUMENT_ID = the ID you copied
Later, from a terminal:
python3 -m connectors.google_docs_service create "خطاب رسمي" "نص الخطاب…"
It creates the draft and, if GOOGLE_DRIVE_FOLDER_ID is set, files it into your shared folder automatically.

Phase 6 · Advanced · Social posting

📣 Buffer

For publishing to social platforms — drafts and posting always pass your approval, like everything else in this system.

First — about that token you pasted in chat: treat it as compromised.

How: Buffer → Publish → Settings → Apps (or buffer.com/developers → your app) → delete/revoke it → then create a fresh one below. Put the new one only in Railway Variables — never in chat.
  1. Where buffer.com/developers (sign in with your Buffer account) → Create an app.
    What Name it e.g. abdulrahman-ai-os → after creating, Buffer shows an Access Token — copy it, keep it private.
  2. What In Buffer Publish, connect the social channels you want (LinkedIn, X, …). Each connected channel has a profile id the API uses.
  3. Where Railway → your service → Variables → add:
    BUFFER_ACCESS_TOKEN = the fresh token (not the one pasted in chat)
