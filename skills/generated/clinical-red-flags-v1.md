# clinical-red-flags

## Purpose
فرز العلامات الحمراء النظامي حسب منطقة الجسم قبل أي خطة علاج طبيعي — دعم قرار لا قرار.

## Procedure
خطوات:
1. حدد منطقة الشكوى (عمودي قطني/عنقي، طرف علوي، طرف سفلي، قِدم/كاحل، صدري/أضلاع، رأس/دوار).
2. افحص قائمة العلامات الحمراء الخاصة بالمنطقة قبل مناقشة أي تدخل:
   - قطني: أعراض ذيل الفرس (اضطراب مثاني/شرجي، خدر سرجي، ضعف متصاعد) = إحالة طارئة فورًا.
     حمى/فقدان وزن غير مبرر/سرطان سابق/كورتيزون طويل/صدمة مهمة = إحالة طبية قبل البدء.
   - عنقي: أعراض النخاع (مشية متعرجة، ضعف يدين تصاعدي، اضطراب دقيق) = إحالة فورية.
     دوخة إيجابية مع دوران العنق بعد صدمة = توقف وقيّم VBI/الشريان الفقري.
   - طرف سفلي: ورم/احمرار/سخونة موضعية مع ألم عجل unilateral = اشتباه DVT (لا تدليك ولا تمارين مقاومة قبل استبعاده، أرسل لتقييم).
   - قِدم: سكري مع فقدان إحساس = قواعد القدم السكرية (لا جراحات جلدية، حمل محدود، فحص حذاء).
   - صدري/أضلاع: ألم صفحي مع ضيق نفس أو غير متموضع بعد صدمة = استبعاد قلبي/رئوي أولًا.
   - رأس: أي فقدان وعي/تقيؤ متكرر/تدهور إدراكي = إحالة، لا تأهيل دهليزي قبل تصوير عند الاشتباه.
3. اذكر للمالك: العلامة المكتشفة + شدتها + الإحالة المطلوبة — بصياغة «دعم قرار، القرار النهائي للتقييم الطبي».
4. سجل النتيجة في مسار CLINICAL_PRIVATE فقط — لا سجل عام.

## Safety
