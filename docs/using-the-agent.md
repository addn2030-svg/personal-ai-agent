# 🖥️ استخدام الوكيل في ChatGPT وVS Code — الدليل العملي

> نظامك مبني على فصل معماري: **المحرك عندك (حتمي: أرقام وقواعد واعتمادات)** + **العقل في LLM (ChatGPT/Claude: تفكير وصياغة)** + **الحالة في state.json (ذاكرة)**. هذا الدليل يصل الأطراف الثلاثة في 5 دقائق.

---

## المسار A — ChatGPT (10 دقائق إعداد، بعدها يوميًا 3 دقائق)

### الإعداد لمرة واحدة
1. في ChatGPT: أنشئ **Project** باسم `Abdulrahman AI OS`.
2. في حقل **Custom Instructions** للـProject الصق محتوى ملفين:
   - `prompts/chief-of-staff.md` (الهوية والقواعد — الأساس الدائم)
   - أضف فوقه سطر: «السياق اليومي سيُلصق في أول رسالة من ملف chat-context.md — لا تخترع خارج ما فيه.»
3. (اختياري حسب حاجتك) أضف حزم المهارات داخل ملفات **Knowledge** للـProject:
   - `prompts/decision-twin.md` — لتحليل القرارات متعدد الأدوار
   - `prompts/voice-to-action.md` — لتفكيك ملاحظاتك الصوتية
   - `prompts/personal-training.md` — للتدريس التكيفي (وضعه في Project منفصل «مدربي» أفضل)
   - `prompts/clinical-intelligence.md` + `prompts/meeting-to-execution.md`

### الروتين اليومي (3 دقائق)
```bash
python3 engine/export_for_chat.py     # أو من VS Code: مهمة «🧠 تصدير سياق ChatGPT»
```
افتح `reports/chat-context.md` ← انسخ ← الصق في محادثة الـProject ← ستحصل على البريف والتغذية الراجعة (مثال حقيقي أدناه).

### 🎭 مثال حوار حقيقي — هذا هو «شكل التغذية الراجعة» الذي ستراه
*(مبني على سياقك الفعلي المصدَّر بتاريخ 2026-08-21 — جرّبه بنفسك بالمحتوى نفسه)*

**أنت تلصق:** محتوى `chat-context.md`

**ChatGPT (الوكيل) يجيب:**

> ☀️ بريف الجمعة → الأحد 23 أغسطس — عبدالرحمن
>
> **🎯 أهم 3 أولويات:**
> 1. **قرار DR-001 (كاشف الأنماط KPI)** — مهلتك تنتهي الأحد: استئناف بخطوة واحدة أو تحويل إلى «متوقف». توصيتي من السياق: عندك 4 مشاريع نشطة ومتوقفة فعلًا واحدة منها — **حوّله إلى متوقف** وخصص طاقتك لـLife Pulse (خطوته التالية محددة).
> 2. **مراجعة قرار الجبيل** — المتوقع 6 عملاء/15 ألف والفعلي 4/11 ألف: قبل التوسع أجب: هل النقص في الطلب أم في قدرتك الاستيعابية؟ (ليس في السياق — أحتاج إجابتك).
> 3. **خمسة عناصر انتظار متأخرة** — أقربها «وكيل الاجتماعات» (12 يومًا بانتظار قرار شراء أداة تفريغ): هذا قرار صغير محتجز مشروعًا — قرره اليوم.
>
> **⚠️ خطر:** كل عناصر الانتظار الخارجي (تأمين، تقنية صحية) تجاوزت 8 أيام — النمط يقترح أن المتابعة الثانية غير موجودة أصلًا.
> **💡 فرصة:** «برنامج وقاية MSD» يظهر في فرصتين جديدتين — هذا نمط طلب متكرر عندك.
> **ما لا أعرفه من السياق:** حالة اجتماعات الأسبوع وKPI القسم غير مدرجة في هذا التصدير — حدّثها لو تريدها في البريف.

**أنت:** أفكر أطلق خدمة وقاية الشركات في جدة قبل الرياض. رأيك؟

**الوكيل (بنمط Decision Twin):**

> أُشغّل الأدوار الثلاثة الأهم باقتضاب:
> **المالي:** تكلفة إطلاق منخفضة (خدمة قائمة على كوادرك) — المخاطرة في وقت البيع لا رأس المال.
> **سوق السعودية:** طلبك الفعلي كله في السياق جاء من **الجبيل والرياض ودمام** — لا توجد فرصة واحدة من جدة في بياناتك. الأقرب للدليل: طلب مؤسسي (صناعي/تأمين) لا جغرافي.
> **محامي الشيطان (إلزامي):** أنت تختار المدينة التي **تعيش فيها** لأنها الأسهل — وهذا ليس معيار سوق.
>
> | | A إطلاق جدة الآن | B Pilot عبر عميل قائم | C تأجيل |
> |---|---|---|---|
> | الدليل من سياقك | 🔴 صفر فرص | 🟢 فرصتان قائمتان | 🟢 |
> | التكلفة | 🟡 وقت بيع | 🟢 شبه معدومة | 🟢 |
> | التعلم | 🟡 | 🟢 | 🔴 |
>
> **التوصية: B** — قدّم البرنامج أولًا لفرصتك الأنشط (شركة صناعية الجبيل، 45 ألفًا) كـPilot بمعايير قياس، وتعلم منها قبل أي توسع جغرافي.
> **سطر السجل الجاهز:** «قرار: إطلاق خدمة وقاية الشركات — الخيار: B Pilot — المتوقع: عميل واحد مُقاس خلال 60 يومًا — مراجعة: {تاريخ+60}». الصقه في صندوق اليوم بتوزيع «قرار».

**أنت:** ذكّرني أراجع ملف مورد الجبيل وخلاصة عندي فكرة لعرض الشركات

**الوكيل:** أولًا — هذه ثلاثة بنود مختلفة، فصلتها:
1. `مهمة` مراجعة ملف مورد الجبيل — موعد؟
2. `قرار مستحق مراجعة` قرار الجبيل (متوقع/فعلي أعلاه)
3. `فكرة` عرض الشركات — أدرجها ضمن مشروع «تطوير الأعمال»
انسخها بصيغة CSV من (نمط voice-to-action) وأدخلها عبر صندوق اليوم.

**→ النتيجة تعود لنظامك:** الصق مخرجاته في `tools/daily-inbox.html` ← `inbox.csv` ← `python3 engine/import_inbox.py`. **الحلقة مكتملة: الحالة → LLM → تغذية راجعة → الحالة.**

> ⚠️ قاعدة صلبة: ChatGPT **لا يرى** ملفاتك ولا يعدل حالتك — هو مستشار يرى فقط ما صدّرته له. كل كتابة تبقى عندك خلف بوابة الاعتماد (C2).

## المسار B — VS Code (بيئة التشغيل الرئيسية)

### إعداد لمرة واحدة
```bash
git clone https://github.com/addn2030-svg/personal-ai-agent.git
cd personal-ai-agent
pip install openpyxl
bash scripts/bootstrap_demo.sh     # يبني بيئة تجريبية ولوحة قيادة فورية
code .
```
لا تحتاج أي إضافة (Extension) — المستودع يتضمن `.vscode/tasks.json` جاهزة.

### يومك في VS Code
`Ctrl+Shift+P` ← **Tasks: Run Task** ← اختر:

| المهمة | ماذا تفعل |
|---|---|
| 🔄 **تحديث اللوحة والبريف** (الافتراضية — ‏Ctrl+Shift+B) | دورة كاملة + فتح اللوحة من `reports/dashboard-latest.html` |
| ⚡ دورة سريعة | مسح انتظار/طلبات قرار (15 دقيقة) |
| 📥 استيراد صندوق اليوم | من `inbox.csv` إلى الحالة ثم تحديث |
| 🛂 عرض طابور الاعتمادات | المسودات بانتظار موافقتك |
| 🧠 تصدير سياق ChatGPT | يولّد `reports/chat-context.md` |
| 📚 مراجعات تعلم اليوم | ما استحق اليوم من سلم التكرار |
| 🧪 اختبار دخان | التحقق الكامل (نفس CI) |

### تدفق موصى به داخل المحرر
```
صباحًا:  Ctrl+Shift+B (لوحة اليوم) → افتح dashboard-latest.html بالمعاينة
نهارًا:  أضف ملاحظاتك في tools/daily-inbox.html → مهمة «📥 استيراد»
قرار؟:  افتح approvals-latest.html → انسخ أمر الاعتماد → شغّله في التيرمنال
تعلم:   مهمة «📚 مراجعات» → أجب → سجّل: python3 engine/learning_engine.py answer LR-00X درجتك
```

## لماذا هذا الفصل أفضل من «GPT يتصل بكل شيء»؟
1. **خصوصية:** بياناتك كله تبقى محلية — ما يُصدَّر هو ملخص اخترته أنت.
2. **صدق:** الأرقام تأتي من محرك لا يهلوس (KPI، انتظار، تجديدات) — وLLM يحلل فقط.
3. **حوكمة:** لا إرسال ولا تنفيذ إلا عبر طابور اعتمادك (C2).
4. **استمرارية:** غيّر ChatGPT إلى Claude غدًا — النظام كما هو، بدّل حزمة الأوامر فقط.
