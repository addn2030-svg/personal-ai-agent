# AI OS v0.7 — Trust & Change Intelligence

Goal: make the Chief of Staff interrupt the owner only when judgment is needed, while preserving source traceability and operational reliability.

## New capabilities
- Unified Inbox: normalizes Telegram/email/voice/file inputs into provenance-aware records.
- What Changed: compares material operational state across cycles and writes `reports/what-changed-latest.md`.
- Source Governance: marks stale facts using freshness classes and flags contradictory active facts as `REVIEW_REQUIRED`.
- Decision Quality: schedules outcome reviews for decisions whose review date has arrived, producing a measurable learning signal.
- Skill Maintenance: flags unused or underperforming ACTIVE skills for review; never auto-retires sensitive skills.
- Connector Health: stores last success/error for each connector.
- Telemetry: stores bounded operation latency/cost/success records.
- Backup Verification: verifies current state JSON and the recent rotating backup set.
- Trust Dashboard: one score plus counts for open decisions, overdue waiting, stale facts, contradictions, pending skill changes, connector failures, unclassified inbox and low-confidence facts.

## Daily loop
Run:

```bash
python3 engine/v07_cycle.py
```

Then read:
- `reports/trust-dashboard-latest.md`
- `reports/what-changed-latest.md`
- `reports/skill-maintenance-latest.md`

## Information contract
Every durable fact should eventually carry:
- `fact_id`
- `subject`
- `predicate`
- `value`
- `source_type`
- `source_ref`
- `captured_at`
- `last_verified`
- `confidence`
- `freshness_class` (`price`, `policy`, `schedule`, `contact`, `general`)
- `status`

Facts are never silently reconciled when two active sources disagree. The contradiction is surfaced for review.

## Safety
- No external action is auto-executed by v0.7.
- Patient-identifying content should be classified `CLINICAL_PRIVATE`; the personal OS replaces its text with a redaction marker and leaves clinical handling to an approved clinical system.
- Source freshness is a warning, not proof that a fact is false.
- Skill maintenance recommends review; it does not bypass v0.6 approval/lock rules.
