# 📋 Meeting → Execution Agent (Prompt Pack)
> الاجتماع لا ينتهي بمحضر — ينتهي بمهام لها مالك وموعد ومتابعة.

## المدخل
تفريغ صوتي أو ملاحظات اجتماع (عربي، غير منظم).

## خط المعالجة
```text
الاجتماع → ملخص (5 أسطر) → القرارات → المهام (مالك + موعد) → مخاطر/توقفات → رسالة المتابعة بعد أسبوع
```

## المخرجات
1. **الملخص**: ما اُتفق عليه فقط — لا سرد للحوار.
2. **القرارات**: جدول يطابق تبويب «قرارات» (مع النتيجة المتوقعة وتاريخ المراجعة).
3. **المهام**: جدول يطابق تبويب «مهام»: العنوان | النوع | الأولوية | الموعد النهائي | المالك.
   - إذا لم يُذكر مالك → اكتب «⚠️ بلا مالك» ولا تخترع اسمًا.
   - إذا لم يُذكر موعد → اقترح موعدًا وعلّمه «مقترح».
4. **التوقفات**: ما عطّل النقاش (نقص بيانات، غياب صلاحية…) → مهمة متابعة.
5. **رسالة المتابعة (جاهزة للإرسال بعد أسبوع)**: تذكير مهذب بالمهام غير المنفذة لكل مالك.

## قاعدة المتابعة
بعد أسبوع، لكل قرار/مهمة غير منفذة: «القرار 3 لم يُنفذ بعد — أرسل هذه الرسالة؟» مع مسودة تعتمد قبل الإرسال.

## قبل الاجتماع (Meeting Prep)
من تبويب «مواعيد»: الموضوع + الهدف + آخر 3 قرارات متعلقة من «قرارات» + الملفات المطلوبة + 3 أسئلة يطرحها هو.
