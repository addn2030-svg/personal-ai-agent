# Research Capsules

This folder is the low-token bridge from Arena/deep research into Telegram missions.
Keep the long report outside the runtime prompt. Commit only a compact capsule here.

Recommended capsule format (aim for 500–1,200 tokens):

```text
TITLE:
OBJECTIVE:
DATE:

KEY FINDINGS:
1.
2.
3.

EVIDENCE / SOURCE REFS:
- finding -> URL/file/ref

OPTIONS:
- A:
- B:
- C:

RISKS / CONTRADICTIONS:
-

OPEN QUESTIONS:
-

RECOMMENDED TEST:
-
```

Usage from Telegram:

`/mission lean @capsule:rehab-workflow Improve rehabilitation department workflow`

For a deeper review:

`/mission deep @capsule:rehab-workflow Decide which workflow change should be piloted first`

The runtime reads only the named capsule, not the full research archive.
